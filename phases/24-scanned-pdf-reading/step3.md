# 배포 파일과 실제 웹 흐름

lint·production build·관련 Chromium·실제 HTTP 검증 후 정확 커밋의 CI를 확인한다. Inngest 함수 산출물에 고정 child script·Tesseract worker와 전이 의존성·core WASM·두 언어 데이터가 포함되어야 한다. 파일 누락 시 CDN으로 대체하지 않는다.

운영에서는 Aside의 기존 로그인으로 PDF 상태 API가 정상 JSON을 반환하는지 확인하고, 허용된 합성 스캔 자료 또는 사용자가 지정한 오류 자료의 본문 준비를 검증한다. 가능한 경우 선택 모델로 실제 질문 한 번을 확인하며 추론을 무단 자동 재시도하지 않는다. 기존 로그인·연결·논문 분석 결과를 보존한다.

원본 dirty checkout의 729개 파일과 index 보존을 확인한다. 원격 CI·운영 배포·실물 PDF 결과는 별도 영수증으로 기록하고, 로컬 성공을 운영 완료라고 표시하지 않는다. 연결앱은 이 OCR 기능 때문에 업데이트하지 않는다.
