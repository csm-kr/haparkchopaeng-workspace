AI 브릿지의 브리를 상태에 맞춰 움직이는 작은 캐릭터로 다듬은 0.1.11 테스트 릴리스입니다.

- ImageGen으로 만든 둥근 브리와 상태별 표정을 적용했습니다.
- 대기할 때는 6초 동안 3px만 천천히 위아래로 움직이고 가끔 눈을 깜빡입니다.
- 실제 작업 중에는 작은 키보드를 두드리며 **일하는 중**을 표시합니다. 연결 중·복구 중·연결 끊김도 표정과 글자로 구분합니다.
- 인사할 때 몸체가 겹치던 현상과 상태가 바뀔 때 위치가 튀던 현상을 고쳤습니다. OS의 동작 줄이기 설정도 따릅니다.

작은 펫은 앱 설정의 **작은 펫 표시**를 켜면 보입니다. 기존 연결 정보와 CLI 로그인은 유지하며, 자동 업데이트는 제공하지 않아 새 설치 파일로 갱신합니다.

Mac은 Apple Silicon(M1 이후), Windows와 Ubuntu는 x64 파일을 사용하세요. 이전과 같은 미서명 테스트 릴리스이며 Mac Developer ID 서명·공증은 포함하지 않습니다. 플랫폼별 검증 범위와 SHA256은 설치 파일 옆의 JSON 메타데이터에 기록합니다.
