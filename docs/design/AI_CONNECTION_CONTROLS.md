# AI 연결 상태와 업데이트 경험

사이드바 계정 위의 `AI 연결`에 8px 상태 점을 둔다. 실제 현재 웹 연결이 성립했을 때 초록색 online 토큰을 쓰고, 확인 중·미연결·오프라인·만료는 중립 회색을 쓴다. 접힌 사이드바도 같은 44px 조작 영역과 상태 설명을 유지한다.

누르면 기존 디자인 토큰의 연결 대화상자를 연다. 기기명과 연결 관리, Codex·Claude Code 두 탭, 해당 도구의 실제 모델 목록과 지원 effort, 작은 사용량 링, AI 브릿지 버전 비교를 순서대로 보여 준다. 탭 이동은 조회만 바꾸며 실제 모델을 선택해야 다음 질문에 적용한다. 미설치·로그인 필요·한도 초과와 지원 모델 부재를 구분한다. effort 미지원은 비활성 안내이며 추정 값을 보내지 않는다. 탭 방향키, 모델·effort 키보드 조작, Escape·완료와 원래 진입점으로 포커스 복귀를 유지한다.

AI 브릿지 버전 행은 앱이 직접 알려 준 설치 버전과 운영 다운로드 목록을 비교한다. 0.1.2처럼 버전을 보고하지 않는 기존 앱은 `설치 버전 미확인`으로 표시하고 최신 파일을 받을 수 있게 한다. 일치하면 `최신 버전이에요`, 설치 버전이 더 높으면 다운그레이드를 제공하지 않는다. Mac 칩이 확인되지 않으면 직접 선택한다.

`업데이트 받기`는 실제 게시한 파일만 내려받는다. 파일을 받은 다음 사용자가 설치 파일을 열어 기존 앱을 교체하고 웹에서 다시 연결한다. 새 앱의 실제 heartbeat가 도착해야 설치 버전과 최신 표시가 바뀐다. 배포나 다운로드 단계에서 설치 완료 문구를 만들지 않는다. 정적 앱 ID, `hapark-connect` 등록, 암호화된 프로필 경로는 그대로 사용한다.

현재 모델·버전·권한 상태는 기존 웹·앱 heartbeat를 따른다. 최신 릴리스 목록은 표시 중 60초, 포커스 복귀, 다시 확인에서 갱신한다. 새 버전 광고는 서버의 게시 manifest와 OS·칩이 일치하는 파일만 사용한다. 웹을 먼저 배포하고 앱을 나중에 게시한다.
