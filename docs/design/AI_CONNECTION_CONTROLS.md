# AI 연결 상태와 업데이트 경험

사이드바 계정 위의 `AI 연결`에 8px 상태 점을 둔다. 실제 현재 웹 연결이 성립했을 때 초록색 online 토큰을 쓰고, 확인 중·미연결·오프라인·만료는 중립 회색을 쓴다. 접힌 사이드바도 같은 44px 조작 영역과 상태 설명을 유지한다.

상태 점은 다른 메뉴의 16px 아이콘 칸에 맞추고, 현재 실행 대상으로 선택한 실제 모델명을 아래 줄에 표시한다. 옆의 20px 사용량 링은 별도 버튼이며 호버·키보드 포커스에서만 기간별 남은 비율·초기화 시각·확인 시각을 연다. 제공자 탭을 둘러보는 동안에는 실제 실행 모델과 링을 바꾸지 않는다. 정보 없음·오래된 관측·0%를 구분하며 정확한 잔여 토큰 수로 표현하지 않는다.

같은 브라우저의 새 탭은 팀별 비밀이 아닌 기기 ID 힌트를 공유 저장소에서 읽고 `status(deviceId)`로 현재 로그인·팀·기기의 실행 허가를 다시 확인한다. 공유 힌트는 승인마다 새 revision을 가지며 이전 연결의 지연 응답이 새 승인을 덮지 못한다. PIN·실행 링크·인증 토큰은 공유하지 않는다. 다른 온라인 PC 목록만으로 연결 대상을 고르지 않으며, 모델·effort 선택과 미완료 연결 요청은 탭별로 유지한다.

사이드바의 `AI 연결`과 프로필의 `AI 연결 관리`는 같은 연결 대화상자를 연다. 관리 창을 여는 것만으로 연결 요청이나 설치 파일 조회를 시작하지 않는다. 연결 전에는 `처음 사용 → 설치 파일 받기`와 `이미 설치함 → AI 브릿지 열기`를 제공한다. 설치 파일과 실제 설치 순서는 앱 열기 실패 전에도 확인할 수 있다. 프로필에는 별도 모델 선택과 질문 입력 폼을 두지 않는다. 모델 설정은 현재 화면 안에서 바꾸며 작성 중인 질문과 선택 자료를 유지한다.

연결을 마친 뒤 기기명·연결 관리, Codex·Claude Code 두 탭, 해당 도구의 실제 모델 목록과 지원 effort, 작은 사용량 링, AI 브릿지 버전 비교를 보여 준다. 탭 이동은 조회만 바꾸며 실제 모델을 선택해야 다음 질문에 적용한다. 미설치·로그인 필요·한도 초과와 지원 모델 부재를 구분한다. effort는 선택 모델이 지원 목록을 제공할 때만 표시하며 추정 값을 보내지 않는다. 상태 확인 전·지원 정보 없음과 반복 사용 안내는 표시하지 않는다. 탭 방향키, 모델·effort 키보드 조작, Escape·완료와 원래 진입점으로 포커스 복귀를 유지한다.

effort 표시에는 CLI 원래 이름인 `low`·`medium`·`high`·`xhigh`·`max`를 사용한다. 실제 선택 모델이 지원한다고 보고한 값만 노출한다.

AI 브릿지 버전 행은 앱이 직접 알려 준 설치 버전과 운영 다운로드 목록을 비교한다. 버전을 보고하지 않는 기존 앱은 미확인 문구와 비교 정보를 숨기고 최신 파일을 받을 수 있게 한다. 실제 설치 버전이 일치하면 `최신 버전이에요`, 설치 버전이 더 높으면 다운그레이드를 제공하지 않는다. Mac 칩이 확인되지 않으면 직접 선택한다.

`업데이트 받기`는 실제 게시한 파일만 내려받는다. 파일을 받은 다음 사용자가 설치 파일을 열어 기존 앱을 교체하고 웹에서 다시 연결한다. 새 앱의 실제 heartbeat가 도착해야 설치 버전과 최신 표시가 바뀐다. 배포나 다운로드 단계에서 설치 완료 문구를 만들지 않는다. 정적 앱 ID, `hapark-connect` 등록, 암호화된 프로필 경로는 그대로 사용한다.

현재 모델·버전·권한 상태는 기존 웹·앱 heartbeat를 따른다. 최신 릴리스 목록은 표시 중 60초와 포커스 복귀에서 갱신하고, 조회 실패일 때만 `다시 시도`를 보인다. 새 버전 광고는 서버의 게시 manifest와 OS·칩이 일치하는 파일만 사용한다. 웹을 먼저 배포하고 앱을 나중에 게시한다.

설치·업데이트 영역은 권장 파일 하나를 기본으로 제시한다. OS는 브라우저에서, 칩은 연결된 앱이 보고한 값과 브라우저 정보를 우선 사용한다. Mac에서 확인할 수 없으면 Apple Silicon을 기본으로 정하고 다른 파일을 고를 수 있게 한다. 실제 게시 목록에 해당 파일이 있을 때만 `AI 브릿지 받기`·`업데이트 받기`를 제공한다. 버튼 아래에는 OS·칩·버전을 적고, 다른 OS 파일은 접힌 `다른 컴퓨터용 파일`에서 고른다. 다른 컴퓨터용 파일을 고르더라도 현재 연결된 PC의 버전 비교 대상은 바뀌지 않는다. 조회 실패·빈 목록·파일 요청 상태를 구분하며 다운로드 요청을 설치 완료로 표시하지 않는다. 세미나의 업데이트 안내도 이 연결 관리 창을 연다.

연결된 뒤 도구 탭에는 `{도구} 터미널 열기` 버튼을 둔다. 앱이 `terminal_v1`을 보고하고 해당 도구가 설치된 경우에만 보이며, 누르면 연결된 PC에서 몇 초 안에 터미널이 열린다고 알린다. 0.1.12 이하 앱에는 버튼 대신 업데이트 안내 한 줄을 둔다. 탭 아래 `실행 중인 작업`은 창이 열린 동안 5초마다와 포커스 복귀 시 현재 세션의 대기·실행 중 작업을 보여 준다. 로딩·빈·에러 상태를 구분하고, AI 채팅 답변만 `멈추기`를 제공하며 나머지는 `열기`로 해당 화면에 보낸다([ADR-034](../agent/ADR.md)).

로컬 앱의 연결·CLI 상태와 향후 웹 SDK 경계는 [AI Bridge 플랫폼 계획](AI_BRIDGE_PLATFORM.md)을 따른다.
