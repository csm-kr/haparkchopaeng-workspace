# 자유 AI 채팅 (ADR-027)

2026-10-18 사용자 지시로 최초의 논문 고정·네 가지 시작 문장·명시적 모델 선택 흐름을 대체한다. 논문 상세의 연구/repro 두 관점과 공통 Figure는 유지한다.

## 대화 화면

- `/ai-chat`을 열면 “무엇을 함께 생각해 볼까요?”와 입력창 하나를 보여 준다. 논문이 없는 팀도 자유롭게 질문한다.
- 입력창에는 메시지, `+` 자료 추가, 전송/중지만 둔다. 네 카테고리, 논문 개수 선택, 모델 선택, 사용량 링, 본문 준비 버튼, CLI 전달 안내 문장을 노출하지 않는다.
- 첫 대화는 입력창을 가운데에 두고, 메시지가 생기면 대화 내용 아래에 입력창을 고정한다. 대화 내용만 스크롤한다.
- 대화 목록은 넓은 화면에서 보조 열로, 좁은 화면에서 대화 목록 버튼의 모달로 제공한다. 새 대화·검색·이전 대화 복구를 유지한다.
- 사용자 메시지와 답변은 정돈된 본문·Markdown·표·코드로 표시한다. 임의 HTML은 실행하지 않는다. 지난 턴의 자료는 해당 메시지에 남는다.

## 자료 호출

1. 입력 중 `@`를 쓰거나 `+`를 누르면 팀 논문·세미나 발표 자료를 검색한다. `@` 앞은 문장 시작 또는 공백이어야 하므로 이메일을 자료 호출로 해석하지 않는다.
2. 제목 검색, 방향키 이동, Enter 선택, Escape 닫기를 지원한다. 한국어 조합 중 Enter는 선택·전송하지 않는다.
3. 선택한 자료는 입력창 안의 작은 칩으로 보이고 제거할 수 있다. 기존 대화에서도 추가·교체·전체 제거가 가능하다.
4. 자료는 선택 사항이다. 서버 문맥의 상한을 위해 논문·세미나를 합해 메시지당 최대 10개를 허용한다. 기존 세 편 제한은 폐기한다.
5. 자료를 선택하는 것만으로 AI를 실행하지 않는다. 질문 전송 후 미준비 논문과 첨부된 세미나 PDF를 Inngest에서 준비하며, 준비 중에도 중지할 수 있다.
6. 세미나는 저장된 요약·핵심 내용·슬라이드 본문과 연결된 PDF의 페이지 텍스트를 제공한다. 파일 경로·스토리지 키·서명 URL·임의 클라이언트 문맥은 모델 입력에서 제외한다. PDF는 텍스트 기반이며 스캔 이미지 OCR은 지원하지 않는다.
7. 과거 답변의 근거는 그 턴의 서버 문맥에 보관한다. 다음 메시지에서 자료를 바꾸더라도 이전 근거를 덮어쓰지 않는다.

## 연결 설정

- 앱 왼쪽 사이드바의 **내 계정 바로 위**에 “연결 설정” 버튼 하나를 둔다. 접힌 사이드바에서도 같은 이름의 아이콘 버튼을 제공한다.
- 버튼을 눌렀을 때만 연결 상태·연결 관리, 실제 사용 가능한 모델, effort 선택을 모달로 보여 준다. 닫으면 원래 버튼으로 포커스를 돌린다.
- 처음 설정하지 않은 자유 채팅만 연결된 CLI의 실제 목록 중 첫 사용 가능한 모델을 쓴다. 같은 팀·기기에서는 사용하거나 직접 선택한 모델을 기억하고, 수동 선택을 우선한다. 실제 카탈로그가 비어 있으면 전송을 막는다.
- 기억한 모델이 로그아웃·한도 초과·목록 삭제로 사용할 수 없으면 전송을 막고 새 모델을 직접 선택하게 한다. 다른 모델이나 CLI로 자동 전환하지 않는다. 새 기기·팀 또는 명시적인 새 연결에서는 초기 선택을 다시 정하며, 논문 분석은 별도의 명시적 모델 선택을 유지한다.
- 실제 모델의 `reasoningEfforts`가 있을 때만 해당 범위의 effort 선택을 표시하고 전송한다. 선택한 값이 지원되지 않으면 확인된 범위의 `medium` 또는 첫 지원값으로 보정한다. 변경은 다음 메시지부터 적용하며 과거 답변은 유지한다.
- 구형 앱이나 지원 정보가 없는 모델은 effort를 표시하지 않고 업데이트·지원 정보 확인을 안내한다. 자유 대화는 계속 허용하고 요청에서 effort 키를 생략한다. 공급자 이름으로 지원 목록을 추정하거나 서버가 임의의 `medium`을 추가하지 않는다. 현재 Claude 카탈로그에는 지원 effort 정보가 없어 선택을 노출하지 않는다.
- 명시한 effort는 서버가 실제 카탈로그로 검증해 해당 턴 문맥의 실행 옵션에 저장하고, 해당 옵션을 지원하는 연결기가 CLI 실행에 전달한다. 웹의 선택 표시만으로 설치된 앱의 실제 적용을 확인했다고 주장하지 않는다.
- CLI 연결·로그인·권한 절차는 기존 연결 모달을 사용한다. 연결과 모델 설정은 대화 입력창에 반복하지 않는다. 논문 분석 화면의 명시적 분석 시작 절차는 유지한다.

## 상태와 권한

자료 준비(`preparing`) → 실행 대기(`queued`) → 답변 중(`running`) → 완료/실패/취소를 구분한다. 준비 중 작업은 연결기가 claim할 수 없다. Inngest는 현재 팀 멤버십과 유효한 grant·기기·작업 시간을 확인하고, 문맥 준비 완료 시 CAS로 실행 대기 상태로 전환한다. 취소된 작업을 되살리지 않는다.

조회는 활성 팀+소유자, 실행과 취소는 현재 웹 세션의 grant를 요구한다. 웹 세션 만료와 네트워크 오류를 구분하며, 전자는 기존 비공개 화면을 지우고 재로그인 경로를 제공한다. 후자는 작성한 초안과 요청 번호를 유지해 재전송한다. 대화 전환 뒤 늦게 도착한 조회·전송 응답이 새 대화를 덮어쓰지 않게 한다.

목록은 최근 100개, 상세는 최근 50턴, 모델 문맥은 완료된 최근 8턴과 원문을 합해 최대 20만 자다. 길이 생략 여부를 표시한다. 개인 채팅은 공유 분석·노트를 자동 변경하지 않는다. 로컬 연결기라는 표현은 공급자에게 자료를 전송하지 않는다는 뜻이 아니다.

## 검증

기존 카테고리·세 편 제한·본문 준비 버튼 테스트는 자유 질문·턴별 자료 선택·자동 준비/실패/취소 테스트로 대체한다. 멱등성, 동시 턴 하나, 중지, 부분 답변, 저장 이력, 세션 만료, 지연 응답 격리, 한국어 조합, HTML 차단 검증은 유지한다. 데스크톱·390px의 자료 검색·연결 설정·모달 포커스 복원을 Playwright에서 검사한다.

코드·브라우저 fixture 검증은 운영 배포와 설치형 연결기 교체를 의미하지 않는다. 기존 설치형 연결기에 effort가 적용되려면 변경된 연결기 코드를 포함한 버전이 필요하다.

운영 수용 확인은 자료 없는 첫 질문과 같은 대화의 후속 질문, 턴별 첨부 자료 보존, 새로 연 이력의 소유자·팀 범위, 현재 세션 연결의 실제 실행을 구분한다. 설치만 마친 상태는 웹 연결이나 실제 추론 성공의 증거가 아니다.
