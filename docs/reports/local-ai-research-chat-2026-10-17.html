하박조팽 / 로컬 AI 연구 보조

IMPLEMENTATION REVIEW · 2026-10-17 · PHASE 13

연결한 AI로 논문을 읽고,
질문을 이어갑니다.

업로드 뒤 API를 자동 호출하던 분석을, 내 PC의 Codex·Claude Code와 사용자가 고른 모델로 실행하도록 바꿨습니다. 별도 AI 채팅 메뉴에서 논문 요약·비교·재현 계획·세미나 질문을 이어갑니다.

웹 946개 통과실제 PostgreSQL 13개 통과Chromium 8개 통과운영 SQL·서명 배포 대기

업로드는 본문 준비만

PDF에서 페이지별 텍스트를 추출합니다. 업로드·본문 준비 단계의 AI 추론은 0회입니다.

모델은 직접 선택

연결한 PC의 실제 카탈로그만 보여줍니다. 기본 모델이나 다른 유료 API로의 자동 전환은 없습니다.

대화와 팀 분석 분리

개인 채팅 기록을 유지합니다. 질문 답변이 팀 분석이나 작성자 노트를 자동으로 바꾸지 않습니다.

사용자가 거치는 순서

  1. 1

    웹에서 ‘AI 연결’

    설치돼 있으면 OS에 등록한 전용 링크가 연결기를 엽니다. 처음에는 OS에 맞는 설치 파일을 받아 실행합니다. 다운로드·실행의 브라우저/OS 확인은 사용자가 합니다.

  2. 2

    처음 한 번, 웹의 6자리 번호를 앱에 입력

    앱은 번호를 빈칸으로 표시합니다. 같은 로그인·팀·기기의 재연결은 확인한 기기 키로 이어집니다. 자동 시작과 펫은 기본 해제입니다.

  3. 3

    사용할 모델을 고르고 논문 분석 또는 AI 채팅

    논문 상세에서 ‘이 AI로 분석’을 누르거나, AI 채팅에서 팀 논문 1~3편을 골라 질문합니다. 작은 링의 상세 한도·초기화 시각·확인 시각은 hover/focus/touch로 확인합니다. 비율은 정확한 잔여 토큰 수가 아닙니다.

  4. 4

    사용 중에는 웹과 연결기를 열어두기

    웹만 45초 실행 허가를 갱신합니다. 로그아웃·팀 변경·멤버 제거 시 회수하고 쿠키가 없어지면 만료로 멈춥니다. 앱을 종료했다면 다음에 웹 버튼으로 다시 엽니다.

브라우저가 임의의 로컬 CLI나 설치 경로를 직접 실행하는 방식이 아닙니다. 최초 설치가 OS에 전용 링크를 등록하고, 그 링크가 사용자의 연결기를 실행합니다. 현재 공개 다운로드 manifest는 비어 있으며 미서명 검증본을 정식 배포 파일로 안내하지 않습니다.

실제 브라우저 화면

코드에서 생성한 실제 화면을 영역별로 캡처했습니다. 화면 속 논문·답변·연결·모델·사용량은 테스트 fixture이며, 운영 연결이나 실제 모델 답변의 캡처가 아닙니다. 이미지를 누르면 확대됩니다.

Aside에서도 격리한 웹앱의 실제 개발 로그인·AI 채팅 메뉴·논문 선택·초기 모델 무선택·연결 전 전송 차단·시작 문장의 초안 입력·논문 분석 카드를 확인했습니다. 그 데이터에는 저장 분석이 없어 Figure·노트의 양 관점은 수동 관측하지 못했고 자동 회귀로 확인했습니다. 실제 AI 실행은 0회이며 QA 탭만 닫고 기존 2개 탭·활성 탭·포커스를 보존했습니다.

AI가 맡는 연구 작업

작업현재 동작
논문 분석연구·재구현 두 관점 JSON과 페이지·원문 인용을 검증한 뒤 저장합니다. 재분석 중/실패/취소에도 기존 결과·Figure·작성자 노트를 보존합니다. Figure와 공통 노트는 양 관점에서 읽습니다.
요약·비교선택한 같은 팀 논문 1~3편의 문제·기여·방법·한계·실험 조건을 정리합니다. 비교 시작 문장은 최소 2편을 요청합니다.
재현 계획·세미나 질문원문에 있는 데이터·모델·학습 조건과 빠진 정보를 구분하고 후속 확인 순서·토론 질문을 제안합니다.
대화 이력·중지소유자와 팀으로 스코프한 이력을 저장합니다. 누적 답변·취소·끊김·재로그인을 구분하고, 같은 요청 재전송으로 중복 추론을 방지합니다.
본문 준비 실패1~30쪽·20MB·12만 자 제한과 스캔 PDF의 읽을 수 없는 본문을 안내합니다. 실패 원인을 보여주고 다시 준비할 수 있습니다.

현재 연결기는 도구 없는 텍스트 실행입니다. Figure 해석은 본문·캡션 기반이며 그림 픽셀을 읽었다고 표시하지 않습니다. 외부 웹·저장소를 방문하거나 코드를 실행하지 않습니다. 채팅은 선택한 자료와 대화를 CLI의 AI 공급자에 전달하며, 오프라인 모델 실행을 뜻하지 않습니다.

설치·운영 배포 상태

Windows

실제 native 암호화·6자리·정상 재개·손상 복구와 NSIS 설치/URI 등록/제거를 검증했습니다. 정식 코드 서명·공개 배포는 별도입니다.

macOS

arm64 실제 native와 arm64·x64 DMG 빌드를 검증했습니다. Intel 실제 실행·Finder 설치·서명·공증은 별도입니다. Windows에서도 개발할 수 있고 Mac 패키징은 macOS CI로 수행합니다.

Ubuntu

24.04 GUI·D-Bus·keyring 전제로 실제 native를 검증했습니다. .deb만 만들고 AppImage는 제외했습니다. 실제 .deb 설치·Wayland·재부팅은 별도입니다.

공통 연결기는 별도 비공개 repo로 분리했고 UI/UX 조사부터 시작하는 local-agent-integration 스킬을 설치했습니다. 호스트 앱은 로그인·팀·권한·DB 큐 REST 계약을 구현해야 합니다. 운영 반영에는 검토 SQL 2개 수동 적용 → 서명한 설치 파일 게시 → 웹/worker 배포 → 실제 설치 연결 검증이 남아 있습니다.

Mac 앱의 외부 배포용 Developer ID·공증은 보통 Apple Developer Program이 필요하며, 회비는 게시자 기준 연 US$99(현지 가격 적용)입니다. 앱 사용자마다 지불하는 비용은 아닙니다. Apple 공식 안내.
