# 브리의 상태별 행동 계획

사용자 요청: AI 브릿지를 귀엽게 다듬고, idle에서는 천천히 움직이며, 연결과 작업 상태에 맞는 행동을 보여 준다. 먼저 계획을 정리한 뒤 구현한다.

## 행동과 표시

기존 라임색 로봇, 그라파이트 얼굴, 플러그 팔과 안테나를 유지한다. 사용자 추가 요청에 따라 ImageGen으로 일관된 상태별 투명 스프라이트를 만들고, CSS는 부유와 프레임 재생만 담당한다. 104×112px 투명 펫 창의 88px 캐릭터를 사용하며, OS 창 자체는 자동으로 이동하지 않는다.

| 실제 상태 | 브리의 표현 | 상태 문구 |
| --- | --- | --- |
| 연결 전 대기 | 6초 주기로 3px만 위아래로 움직이는 부유, 가끔 깜빡임과 미소 | 쉬는 중 |
| 연결 요청·번호 확인 | 귀를 기울이는 기울기와 안테나 | 연결 중 |
| 연결됨·작업 없음 | 편안한 얼굴과 느린 부유 | 준비됐어요 |
| 실제 작업 실행 | 집중한 눈, 작은 키보드와 타이핑 움직임 | 일하는 중 |
| 연결 복구 | 기다리는 눈과 천천히 살피는 안테나 | 연결 확인 중 |
| 웹 권한 종료 | 내려간 안테나와 걱정스러운 입 | 다시 연결 |
| 연결 오류 | 걱정스러운 표정과 물음표 | 연결 확인 |

작업·복구·연결 끊김 문구는 계속 보인다. 평소 대기·준비 문구는 호버할 때 나타나 캐릭터를 조용하게 유지한다. 호버 미소는 상태 문구를 덮지 않는다. 동작 줄이기에서는 반복 동작을 모두 멈추고, 정적인 표정·소품·글자로 상태를 구분한다.

## 상태의 근거

`ConnectorSession.getState()`의 `status === 'connected' && currentJobId`만 실행 중 표시의 근거로 사용한다. 복구·권한 종료와 앱의 새로운 연결 요청이 이전 작업보다 우선한다. 작업 ID 제거는 실패·취소도 포함하므로 완료 축하나 성공 알림을 추정하지 않는다. 진행률과 생각·작성 단계도 표시하지 않는다.

## 구조

메인 프로세스에서 표시용 mode 하나를 파생한다. 메인 창에는 기존 상태와 mode를 함께 보내고, 펫에는 mode만 단방향 전달한다. 펫 전용 preload는 상태 구독만 제공하며 전체 연결앱 API를 노출하지 않는다. 첫 로드는 `did-finish-load`에서 최신 상태를 다시 발행한다. 질문·답변·작업 ID·계정·기기 키는 펫으로 보내지 않는다.

공용 `renderer/bri-state.mjs`가 상태 우선순위와 고정 문구를 소유한다. `pet.js`는 DOM에 mode와 고정 문구를 적용하고, ImageGen 스프라이트와 CSS가 표정과 움직임을 담당한다. 메인 창에서도 같은 mode로 작업·복구 배지를 표시한다. 펫 기본 꺼짐, 드래그 영역과 앱 종료 정책을 유지한다.

## 구현 순서와 검증

1. **상태 전달:** 순수 상태 선택기와 최소 preload의 실패 테스트를 먼저 작성한다. 연결 전환·복구·권한 종료·작업 중·실패/취소 후 대기, 실제 main의 펫 생성·상태 발행·재로드와 패키징 포함을 검증한다.
2. **캐릭터:** 상태별 ImageGen 스프라이트·CSS, 짧은 상태 문구와 메인 창 작업 표시를 구현한다. 실제 104×112px에서 한글 문구·소품·눈·안테나가 잘리지 않게 한다.
3. **실제 화면:** 격리 Electron에서 각 상태·호버·동작 줄이기·흰색/어두운 배경·드래그 면적·포커스를 확인하고 connector 회귀를 실행한다. 화면 배율을 실제 캡처 픽셀과 맞춘다.

기존 설치 앱이나 계정 설정을 바꾸지 않는다. 로컬 소스와 격리 화면 검증이 이번 범위이며, 설치본 배포·실제 계정 추론 성공은 별도 사실이다.

## 설계 비교

메인이 mode를 정해 단방향으로 전달하는 안을 기본으로 한다. 펫이 revision을 가진 사실을 조회·구독하는 안은 초기 응답 순서 문제를 해결하지만, 읽기 IPC와 별도 revision 관리가 추가된다. 기존 메인의 발행 지점과 로드 완료 이벤트를 사용하면 구독 API 하나로 같은 요구를 충족한다. 두 안에서 공통으로 제안한 중복 상태 DOM 갱신 방지와 동작 줄이기의 정적 작업 표시를 반영한다.
