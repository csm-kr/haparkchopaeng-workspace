# 하박조팽 업데이트 노트

## 2026-10-18 · 스캔 PDF 본문 읽기 개선

- 글자를 선택할 수 없는 스캔·화면 캡처 PDF도 필요한 페이지의 문자를 인식해 논문 분석과 대화의 자료로 읽도록 개선했습니다. 짧은 텍스트 PDF와 기존에 읽은 본문도 유지합니다.
- 문자 인식으로 읽은 논문에는 안내를 표시합니다. 인식 오류가 있을 수 있으므로 중요한 수치·인용은 원문 PDF와 함께 확인해주세요.
- 자료 준비 중 취소하거나 PDF를 바꾸면 이전 본문으로 새 답변을 시작하지 않도록 확인합니다. 페이지 읽기가 실패하면 일부 본문을 완성된 결과로 저장하지 않습니다.
- PDF 본문 읽기를 위한 별도 AI API 키나 앱 추가 설치는 필요하지 않습니다. 파일은 20MB까지, 논문 30쪽·발표 자료 150쪽까지 읽습니다.

## 2026-10-18 · AI 연결과 모델 선택

- 같은 브라우저의 새 탭에서도 이미 승인한 PC를 다시 확인해 모델을 선택할 수 있습니다.
- 왼쪽 `AI 연결`의 정렬을 맞추고 현재 선택 모델과 작은 사용량 링을 표시합니다. 링에 마우스를 올리거나 키보드로 이동하면 남은 구독 한도와 확인 시각을 볼 수 있습니다.
- effort는 각 모델이 지원하는 `low`·`medium`·`high`·`xhigh`·`max` 이름으로 표시합니다.
- 다른 탭에서 새로 연결하거나 연결을 해제했을 때, 이전 요청의 응답이 새 상태를 덮지 않도록 했습니다.

## 2026-10-17 · 라이브 안정성 및 화면 공유 개선

### 화면 공유

- 공유를 중지하면 크게 남아 있던 검은 화면을 정리하고 기본 참가자 화면으로 돌아갑니다.
- 발표 중 **얼굴 띄우기**를 누르면 다른 참가자들의 얼굴을 별도 작은 창으로 볼 수 있습니다. 전체 화면이나 다른 앱으로 발표할 때도 사용할 수 있습니다.
- 작은 창의 크기를 조절해도 얼굴이 잘리지 않도록 배치를 개선했습니다. 공유를 끝내거나 라이브에서 나오면 창도 닫힙니다.
- 얼굴 띄우기는 데스크톱 Chrome·Edge의 지원 환경에서 사용할 수 있습니다. 참가자가 카메라를 끈 경우에는 아바타가 표시됩니다.

### 라이브 시작과 종료

- 화면·음성 서버의 응답이 지연돼도 라이브 종료 상태를 먼저 반영합니다.
- 발표자 외에 **해당 팀의 소유자·관리자**도 라이브를 종료할 수 있습니다.
- 종료 직후 새 라이브를 시작해도 이전 종료 응답이나 늦은 알림이 새 라이브를 닫지 않도록 수정했습니다.
- 여러 명이 동시에 시작해도 같은 팀에서는 라이브 하나만 열립니다. 이미 열린 라이브가 있으면 입장을 안내합니다.
- 종료 요청이 반복되어도 종료 알림과 룸 정리를 중복 실행하지 않습니다.

### 연결 복구와 팀 구분

- 인터넷 연결 복구, 실시간 알림 재연결, 앱으로 돌아왔을 때 현재 라이브를 다시 확인합니다.
- 연결이 끊긴 동안 라이브가 끝나거나 새로 시작되었으면 최신 세션으로 화면과 접속 정보를 바꿉니다.
- 팀별 라이브 알림과 연결 상태를 구분하여 다른 팀의 종료가 현재 팀에 영향을 주지 않도록 했습니다.
- 발표 자료 다운로드에도 활성 팀의 접근 권한 검사를 적용했습니다.

### 사용 방법

1. 세미나에서 화면 공유 또는 PDF 공유를 시작합니다.
2. 참가자 목록의 **얼굴 띄우기**를 누릅니다.
3. 작은 창을 원하는 위치로 옮기고 발표합니다.

앱 업데이트 후에는 열려 있는 페이지를 한 번 새로고침해주세요.
