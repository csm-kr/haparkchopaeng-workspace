데이터베이스 & 모델

Prisma + SQLite로 시작하며 Postgres 이전 경로를 유지합니다(ADR-010). 19개 모델이 6개 도메인으로 묶입니다. SQLite 제약상 enum은 String(허용값은 주석/앱 검증), 배열 스칼라는 Json으로 모델링합니다.

🗄️
SQLite 제약 회피. 역할·관점·상태 등은 String(허용값 주석), tags·keypoints·slides·payload는 Json. DateTime은 Prisma 타입이지만 API 경계 DTO에서는 ISO 8601 문자열로 직렬화합니다(ADR-015).

Member·Invite·Workspace·Job은 FK 관계 컬럼(uploadedBy, authorId, presenterId, memberId 등)으로 논리적으로만 연결됩니다 — Prisma relation이 아니라 ID 참조(앱에서 무결성 관리). 작성자/소유자 ID는 항상 서버 세션에서 주입합니다.

도메인 1 · 워크스페이스 / 팀 / 인증

Workspace

CRITICAL row는 단 하나만 존재 — 멀티테넌트 아님(ADR-007). slug unique.

Member

id는 "ha|bak|jo|paeng". role·presence·availability는 String(앱 검증). color는 CSS 토큰명.

Invite

CRITICAL 합류는 초대 토큰 검증을 통해서만 — 공개 가입 없음(ADR-007). status: pending/accepted/revoked.

도메인 2 · 논문 / 분석

🔥
업로드는 PDF 전용(ADR-003) — kind 같은 타입 필드를 두지 않습니다. 분석 실패가 Paper 저장을 막지 않습니다 — analysisStatus=failed로 두고 /reanalyze로 재시도합니다.
모델핵심
PaperpdfUrl(다운로드 유일 액션), analysisStatus(pending/ready/failed). tags: Json. analyses·figures·notes 보유.
Analysislens는 research|repro 두 관점만(ADR-004). @@unique([paperId, lens]). payload는 관점별 구조화 필드 전체(Json).
Figure두 관점 공통(특정 lens 없음). sourcePage(PDF p.N 출처), interpretation(평이한 해석), imageUrl?(없으면 수동 업로드 대기).
SectionNote{sectionId, lens}로 스코프. figures 노트는 항상 lens="any"(ADR-005). authorId 표기 필수. @@index([paperId, sectionId, lens]).

도메인 3 · 발표 자료 / 회고

모델핵심
Presentationslides: Json [{title, subtitle?, body}], keypoints: Json, summary. assets·versions·comments 보유.
PresentationAssettype: pdf|ppt|note, size, url.
PresentationVersionver("v3"), byId, note — 자료 버전 이력.
Comment@멘션은 본문 토큰으로 보존. slide?(특정 슬라이드 참조). 회고 댓글은 발표 자료에 귀속(논문 상세엔 댓글 패널 없음, ADR-004).
Reaction@@unique([commentId, memberId, emoji]) — 중복 반응 방지.

도메인 4 · 스케줄 / 책임

🔥
자동 생성 금지(ADR-006) — @@unique([year, month])이며 row 부재 = 빈 달. GET이 월을 만들지 않습니다. version은 낙관적 락 — 두 관리자 동시 편집 시 저장 충돌을 막습니다(저장 시 If-Match 불일치 → 409).
모델핵심
ScheduleMonthrotationPointerAfter(저장 후 다음 시작 인덱스 — 순번 전진 결과), saved, version. weeks 보유.
ScheduleWeekweek·date·time·presenterId?·topic?·confirmed·status(done|upcoming, current는 파생)·presentationId?.
FineConfigyear PK. finePresenter(발표자 불참, 기본 30000), fineAbsent(일반 불참, 기본 10000).
MemberLedger@@unique([year, memberId]). count(참여)·missedPresenter·missedAbsent·paid. 누적 벌금은 파생 계산(저장 안 함).

도메인 5 · 라이브

🔥
동시 active 세션은 1개 — 앱 전역 live 상태와 1:1 매핑(ADR-001). /start가 이미 active면 409.
모델핵심
LiveSessionactive, presenterId, cloudflareLiveInputId?, recordingUrl?(종료 후 녹화본), startedAt/endedAt. participants 보유.
Participant@@unique([liveSessionId, memberId]). joinedAt/leftAt — leave는 본인 leftAt만 기록.

도메인 6 · 백그라운드 잡 (ADR-013)

모델핵심
