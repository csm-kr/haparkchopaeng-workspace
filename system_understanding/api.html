API 설계

모든 서버/외부 로직은 Next.js App Router의 route handler(app/api/**/route.ts) 또는 Server Action에서만 처리됩니다. 클라이언트 컴포넌트는 DB·Cloudflare·스토리지를 직접 호출하지 않습니다.

🔒

인증 필수

모든 엔드포인트가 세션 요구. 미인증 → 401
🏢

단일 테넌트

워크스페이스 ID를 경로에 노출하지 않음. 암묵적으로 그 하나에 속함
📨

응답 포맷

{ data } 또는 { error: { code, message } }

권한 표기: 🔒 인증(전부) 👑 관리자 전용 ✍️ 작성자/관리자

논문 · 분석

메서드경로설명권한
GET/api/papers논문 목록(필터 "전체"만)🔒
POST/api/papersPDF 업로드 또는 arXiv URL로 생성🔒
GET/api/papers/:id논문 + 분석 + figure🔒
GET/api/papers/:id/pdf원문 PDF 다운로드(서명 URL)🔒
GET/api/papers/:id/analysis?lens=…관점별 분석(research|repro)🔒
GET/api/papers/:id/notes섹션 노트 목록🔒
POST/api/papers/:id/notes섹션 노트 추가 {sectionId, lens, title, body}🔒
DEL/api/notes/:id노트 삭제✍️
POST/api/papers/:id/reanalyze분석 재시도(실패/대기 시)🔒
🔥
업로드는 application/pdf만 허용 — 그 외 → 415. arXiv URL은 서버(워커)가 PDF를 가져옵니다. 업로드 성공과 분석 성공을 분리 — 분석이 실패해도 Paper를 저장하고 analysisStatus: pending|failed로 응답. 노트 작성자는 서버가 세션에서 강제 주입(클라 authorId 불신). sectionId==="figures"면 lens를 any로 강제.

스케줄 · 책임

메서드경로설명권한
GET/api/schedule/:year/:month해당 월(없으면 null = 빈 달) + version🔒
POST/api/schedule/:year/:month/draft초안 생성(서버가 토요일·순번 계산)🔒
PUT/api/schedule/:year/:month저장(영속화 + 순번 전진) — If-Match: version🔒
GET/api/fines/:year벌금 설정 + 멤버 장부🔒
PUT/api/fines/:year벌금 금액 수정👑
🔥
GET이 월을 자동 생성하지 않습니다 — 없으면 data: null(ADR-006). 순번 포인터 전진은 PUT 시 서버에서 원자적으로(클라가 포인터 안 보냄). 동시 편집 충돌은 낙관적 락으로 — If-Match version 불일치면 409. 누적 벌금은 서버에서 파생 계산(저장 안 함).

라이브 세미나 (Cloudflare Stream Live)

메서드경로설명권한
GET/api/live현재 세션(없으면 null)🔒
GET/api/live/streamSSE — live.started/ended · @멘션 푸시🔒
POST/api/live/startCloudflare Live Input 생성 → 세션 시작🔒
POST/api/live/:id/join참가 등록 + 시청용 HLS🔒
POST/api/live/:id/leave본인 퇴장🔒
POST/api/live/:id/end세션 종료(전체) + 녹화 처리✍️(발표자/관리자)
🔥
/start 응답(발표자 전용): { rtmps, srt, playback{hls} } — Stream Key는 발표자 본인에게만. /join 응답(시청자): 재생용 { playback{hls} }만 — 송출 자격증명 절대 미포함. 동시 active 1개 — 이미 있으면 409. /end만 전역 종료, /leave는 본인만. 전이 전파는 SSE.

업로드 / 스토리지 · 웹훅

메서드경로설명권한
POST/api/uploads/presign프리사인 업로드 URL 발급(PDF만)🔒
POST/api/webhooks/cloudflare녹화 완료 등 Stream Live 이벤트(HMAC 검증)서명 검증

프리사인 직접 업로드: 큰 PDF는 클라이언트→스토리지 직접(서버는 서명만), 완료 후 POST /api/papers에 객체 키 전달. 웹훅은 세션 인증이 아닌 HMAC 서명으로 보호.

상태 코드 → UX 매핑

서버 코드는 일관되게, 클라이언트는 따뜻한 한국어로 번역합니다(원문 노출 금지).

코드사용처사용자에게 보이는 카피
400검증 실패(zod)인라인: "내용을 확인해주세요"
401미인증/세션 만료부드러운 재로그인 유도(작성 내용 보존 시도)
403권한 부족"이 작업은 관리자만 할 수 있어요"
409충돌(이미 라이브 중, 월 편집 충돌)"이미 OOO님이 시작했어요. 입장할까요?"
415PDF 외 업로드"PDF만 올릴 수 있어요"
5xx서버/외부 오류"잠시 후 다시 시도해주세요" + 다시 시도

분석 실패는 HTTP 에러가 아니라 Paper.analysisStatus로 표현 — 논문은 정상 응답.
