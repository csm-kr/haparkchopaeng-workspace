하박조팽 리서치 워크스페이스

매주 토요일 세미나를 진행하는 4인 리서치 그룹의 반복 활동 — 라이브 발표, 논문 두 관점 분석, 자료 아카이빙, 일정·책임 관리 — 을 하나의 따뜻하고 마찰 없는 비공개 워크스페이스로 모으는 단일 테넌트 제품입니다.

스케줄 · 책임

이 시스템을 규정하는 5가지 결정

  • 단일 테넌트 · 초대 전용 (ADR-007) — 워크스페이스 row는 단 하나. 공개 가입 없음, 서명된 초대 토큰으로만 합류.
  • 업로드 성공 ≠ 분석 성공 (ADR-013) — 분 단위 Claude 분석은 durable 잡 러너로(ADR-016). 분석이 실패해도 논문·원문 PDF는 살아있고 재시도만.
  • live는 앱 전역 상태 (ADR-001/014) — 동시 active 세션 1개, SSE 푸시로 모두에게 즉시 일관.
  • 스케줄 자동 생성 금지 (ADR-006) — 빈 달은 진짜 비어 있음. 명시적 편집→저장→확정, 낙관적 락으로 동시 편집 보호.
  • 읽기=RSC 서버 조회, 쓰기=Server Action/route handler (ADR-015) — 클라이언트는 DB·외부 서비스를 직접 보지 않음.
